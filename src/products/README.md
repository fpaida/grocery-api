# Grocery API

## Description
A RESTful Grocery API built with Node.js, Express, and PostgreSQL.

## Technologies
- Node.js
- Express
- PostgreSQL
- Render
- GitHub

## API Endpoint

GET /api/v1/products

Returns a list of grocery products in JSON format.

## Live API

https://grocery-api-o3m1.onrender.com/api/v1/products
